VITAL PWA prototype

This is an early browser prototype. It supports local food logging and macro totals, daily calorie target, manual sleep/HR/HRV/steps logging, workout-day creation/removal, profile editing, JSON export and local data deletion.

To install on iPhone: these files must first be hosted on an HTTPS static website. Open that website in Safari, tap Share, then Add to Home Screen. The ZIP itself is not an installable iOS app.

Data stays in local browser storage on this device. There is no cloud account/sync, HealthKit, wearable sync, barcode/OCR service, AI backend or validated recovery/strain/biological-age calculation yet. A native iOS app with HealthKit requires an appropriately signed iOS build and Apple permissions. Never treat manually entered or estimated values as medical measurements.
